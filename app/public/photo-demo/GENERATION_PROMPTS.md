# Generated photo assets

Created with the built-in image_gen tool. The second image is an edit of the first; the original generated files are retained in the Codex generated_images directory and copied into this project's public/photo-demo folder.

Prompt 1 — empty reference:
"Use case: scientific-educational. Asset type: synthetic reference photo for a classroom seat-occupancy attendance prototype. Generate ONE landscape photorealistic empty classroom image, viewed from a high fixed ceiling camera looking nearly straight down with only a slight perspective. EXACTLY 24 clearly separated identical single-student desk-and-chair stations arranged in a regular rectangular grid: 4 horizontal rows, each row exactly 6 columns. Fill most of frame with this grid. All 24 chairs are EMPTY. Desks light grey, chairs medium blue, uniform pale grey floor, soft even daylight, no shadows obscuring seats, no bags, no laptops, no people, no text, no numbers, no labels, no logos. All chair seats must be completely visible from above. Keep rows and columns aligned with image axes and each station spatially separate with generous aisles. The upper margin represents the front of the room. Image suitable as a clearly synthetic educational demonstration, no actual student data."

Prompt 2 — occupied edit of image 1:
"Edit target: the provided empty 4-row by 6-column classroom photo. Primary request: create its occupied attendance demonstration version. Keep the camera, crop, resolution, floor, desks, chairs and exact station coordinates IDENTICAL to the reference. Add exactly 20 fictional adult university students sitting naturally in the blue chairs, viewed from the same overhead camera, working at their desks. Leave exactly these FOUR stations empty: row 1 column 2; row 2 column 5; row 3 column 1; row 4 column 4. Rows count from top to bottom, columns from left to right. Every other chair has ONE seated adult. Students wear varied casual shirts and trousers; natural dark hair, varied skin tones. Do not add standing people or extra furniture, bags or objects on empty seats. Preserve all unchanged background pixels as closely as possible so the pair is useful for educational image-difference seat occupancy. No text, no labels, no logos. Treat desk and chair geometry as invariant. Only add the seated people and their small local shadows."
