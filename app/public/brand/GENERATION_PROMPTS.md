# Acadence logo provenance

Method: built-in image generator, transparent background. The generated concept is archived outside the working project. `acadence-mark.svg` is a clean hand-authored vector interpretation of the book/A/check direction for UI use; it is not an automatic raster trace. The two PNG install icons are rendered from that SVG.

## Selected concept prompt

Use case: logo-brand. Generate a final production logo symbol for Acadence. A clean geometric letter A formed from two folded book ribbons, with a simple attendance check in the center. Two solid colors only: cornflower blue #78A9FF on the left ribbon and off-white #F4F7FF on the right and check. Completely flat solid opaque fills, immaculate smooth silhouette, crisp digital vector-like logo, no texture whatsoever, no speckles, no distressed edges, no shadows, no gradient, no glow, no tiny details. Solid large shapes readable as app icon. Balanced square composition, symbol fills 78 percent of canvas, centered. True transparent background. One symbol only, no words, no text, no sheet or mockup. An elegant premium academic application logo for a black website.

## Production assets

- `acadence-mark.svg`: transparent scalable symbol.
- `acadence-logo.svg` and `acadence-logo.png`: presentation lockup on charcoal, with a readable wordmark.
- `icon-192-v2.png` and `icon-512-v2.png`: dark-background install icons.

Palette: cornflower blue `#78A9FF`, off-white `#F4F7FF`, black/charcoal application background. The website retains a live-text wordmark for readability.
